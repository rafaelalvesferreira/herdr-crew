# herdr-crew v0.1 design

## Intent

Publish, as a public Claude Code plugin, skills for coordinating coding agents inside Herdr that were developed and used privately. Audience: anyone running Herdr with Claude Code who does not know the author's workflow.

## Goals

- One repo, one plugin, several skills (same shape as obra/superpowers).
- English, generic examples, no organization-specific references.
- Do not copy Herdr's own skill; every skill checks `HERDR_ENV=1` and runs `herdr --skill` when Herdr's skill is not in context.
- Keep the behavior that works today; change only what is listed below.

## Changes from the private versions

- `coordinating-agents-in-herdr`:
  - Split into a core (answer-vs-delegate triage, helper contract, return address, background safety net, `/exit`, resume by session id, helper table, `herdr worktree create`, safe worktree removal, safety rules) and **default conventions** (worktree for every edit, one coordinator per project with hand-off, coordinator stays in its checkout, labels, helper flags), which the user's own instructions override.
  - The first time a convention does something the user did not ask for, the agent says so in one line with how to turn it off.
  - "Work here" turns off the worktree-for-edits convention for the whole session (previously per request, and only after insisting).
  - Worktree removal procedure and the full mistakes table moved to `references/`; the SKILL.md keeps a short version and the silent-damage red flags.
  - Codex helper guidance kept (out of scope is running the plugin under Codex, not starting Codex helpers).
- `watching-commands-in-herdr`: general rule first; signature table becomes examples across common tools.
- `fixing-pane-size-in-herdr`: straight translation; documents `stty -f` for macOS.

## Non-goals (v0.1)

- Support for running under Codex, OpenCode or other harnesses.
- Further improvements (planned for a second PR after a design discussion).
- Hooks, commands, automated tests in CI.

## Anti-goals

- A new user installs it and, without warning, agents start opening worktrees and workspaces.
- Losing behavior that works today.
- Forking Herdr's own skill.

## Approaches considered

1. Faithful port plus the decided changes, verify, improvements later — chosen: the diff stays reviewable and translation does not mix with behavior changes.
2. Rewrite with improvements in v0.1 — rejected: hard to attribute regressions.
3. Literal translation only — rejected: ships an opinionated flow with no way out.

## Platform

Tested on Linux/WSL. macOS should work, untested.
