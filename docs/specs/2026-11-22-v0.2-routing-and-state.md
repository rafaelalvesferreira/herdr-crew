# herdr-crew v0.2: small edits, model routing, durable state

## Intent

Make `coordinating-agents-in-herdr` fluid: fewer questions, no surprise overhead for trivial edits, nothing written inside the user's checkout.

## Decisions

- **Small edits stay in place.** One file, a few lines, nothing to run to check it: edit in the current checkout, no worktree, no commit unless asked. Anything larger goes to a worktree. The exception covers only the agent's own checkout; work in another checkout always goes to a helper there.
- **Fewer questions when starting work.** Project name defaults to the repository's directory name and the task name is derived from the request; both are stated so the user can correct them. The agent asks only when project prefixes are already in use for that repository.
- **Model routing is opt-in and never asked.** `.claude/herdr-routing.json` (project, then `~/.claude/`) maps a role (`coordinator`, `reviewer`, `builder`, ...) to a model id or alias. The key is the agent name without its numeric suffix. No file or no key: no `--model`, the agent uses the user's default.
- **State lives outside checkouts.** Helper table and saved contracts go to `~/.herdr-crew/<project>/`. Files inside a checkout dirty `git status`, show up in reviews and block worktree removal.
- **Recovery checks before re-running.** When a helper cannot be resumed, the coordinator first looks for a result that already exists; only then it starts a new helper from the saved contract, and says so.
- **Contract has seven blocks.** `COMPARISON_BASE` names what "the diff" means; default is `origin/<default branch>` read from git, not a hardcoded `main`.
- **Helper names are unique server-wide.** The numeric suffix is the lowest one `herdr agent list` does not show.

## Rejected

- Asking for the coordinator's model on every session: friction on every load, and the running session's model cannot be changed by a skill.
- A JSON registry of pane occupancy: Herdr already is the source of truth (`herdr pane list`, `herdr agent list`); a second copy goes stale and races.
- Saving contracts under `.claude/` in the checkout: see "State lives outside checkouts".
